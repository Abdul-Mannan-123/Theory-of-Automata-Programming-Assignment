# Testing Report

## Test environment and command

The project uses Python's built-in `unittest` runner; no third-party packages are required. Run from the project directory:

```powershell
python -m py_compile automata_toolkit.py test_automata_toolkit.py
python -m unittest -v test_automata_toolkit.py
```

The suite currently defines 97 unit tests.
